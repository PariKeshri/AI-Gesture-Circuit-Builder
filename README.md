An interactive circuit design application that allows users to place, move, and connect electronic components using hand gestures detected through a webcam.

The project combines computer vision, hand tracking, OpenCV, and Python to create a touch-free virtual electronics workspace.

Features
1.Gesture-based interaction using a webcam
2.Index-finger-based interaction for precise component control and wiring
3.Place electronic components using hand gestures
4.Move components around the circuit workspace5
5.Connect component terminals
7.Undo / Back functionality
8.Automatic circuit validation
9.Support for basic electronic circuits
10.Battery and current-source based circuits
11.LED circuits
12.Multiple resistor values
13.Two-terminal component wiring system
14.Interactive circuit-building interface
15.Component library with circuit symbols


Project Objective : 
The objective of this project is to create a touch-free electronics design environment where users can construct circuits using hand movements instead of a traditional mouse-and-keyboard interface.

Technologies :
1.Python
2.OpenCV
3.MediaPipe
4.NumPy
5.Computer Vision
